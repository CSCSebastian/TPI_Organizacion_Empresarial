# TPI_Organizacion_Empresarial

# Chatbot de Gestión de Vacaciones

## Descripción
Bot para solicitud de vacaciones desarrollado para TP Integrador de Organización Empresarial.

## Instalación
1. Clonar el repositorio
2. Ejecutar `python bot_vacaciones.py`

## Comandos
- 1: Consultar saldo
- 2: Solicitar vacaciones
- 3: Ver historial
- 0: Salir

## Tecnologías
- Python 3.7+
- CSV para persistencia
- Máquina de estados
